# Realtime Media Playground

A learning project exploring concepts used in real-time communication systems such as WebRTC and RTP.

## Goals

- UDP networking
- RTP-style packet headers
- Jitter measurement
- Packet loss detection
- Thread pools
- Modern C++20

## Build

mkdir build
cd build
cmake ..
cmake --build .
